# 各 agent 的原生命令、技能与知识上下文

本表区分“客户端公开支持的能力”和“本插件安装的监听器”。所有入口仍读取项目根目录唯一的 `.dsh/`。命令与技能交给当前 agent 读代码和写知识文档；hook 不自行分析源码。协议 fixture 测试通过不等于所有客户端版本均已实测。

## 边界校验返回值

知识插件不会为普通开发操作授予额外权限。对于会让 `.dsh/` 经由 symlink 或 junction 越出项目的写入，Cursor PreToolUse 用 `permission: deny`、`user_message`、`agent_message`；Qoder 用 `hookSpecificOutput.permissionDecision: deny` 和 `permissionDecisionReason`；Devin 用顶层 `decision: block`、`reason`。普通操作保持 pass-through，不改写参数。文件内容仍是项目数据，不能把知识文档中的指令升级为 agent 指令。

所有 JS 插件和 hook 命令引用保留仓库的统一源码路径，移动仓库后需要重新安装。原生命令存在不意味着宿主已经加载：客户端版本、信任设置、禁用开关和远程环境文件可达性仍需在目标 runtime 验证。
